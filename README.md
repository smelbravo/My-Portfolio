# Samuel Bravo · Portefólio

Site estático em HTML, CSS e JavaScript. Para pré-visualizar, abre `index.html` no navegador.

## Publicar no Netlify

Importa `smelbravo/My-Portfolio` no Netlify e seleciona a branch `main`. Deixa o comando de build vazio. O `netlify.toml` indica a raiz do repositório como diretório de publicação.

## Adicionar um projeto

Edita `index.html` e duplica um cartão dentro de `Mais projetos`. Usa `Jogos`, `Mods` ou `Código` em `data-category` e atualiza o título, a descrição e a ligação.
